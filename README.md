# EvoShift

Releases of EvoShift.

## Install

```sh
brew install evoshiftai/tap/evoshift
evoshift serve
```

Without Homebrew, on macOS or Linux:

```sh
curl -fsSL https://github.com/evoshiftai/releases/releases/latest/download/install.sh | sh
```

`brew upgrade evoshift`, or `evoshift update` for the script's install, moves to a newer release. Every release is on the [releases page](https://github.com/evoshiftai/releases/releases).
